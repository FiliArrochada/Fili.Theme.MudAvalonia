# 0.9.3

[All versions](README.md)

Two fixes found by moving an app onto 0.9.2. A `TextBox` whose `Text` is null no longer logs a
binding error from its hidden counter, which every such field did. A checkbox in a `DataGrid` cell
is MudBlazor's table checkbox, a 32px circle pulled in 4px, so a selection column no longer makes
its rows 81px tall; they are 57.
