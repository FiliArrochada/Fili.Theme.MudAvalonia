# 0.5.0

[All versions](README.md)

More of MudTabs, MudProgressLinear, MudButton and MudChip.

## What changed

- **Tabs:** MudTabs' `Position` through `TabStripPlacement`, `Elevation` as `elevation*` and
  `SliderColor` as `slider-{colour}`.
- **Progress:** MudProgressLinear's `Striped` as `striped`.
- **Icons in content:** MudButton's `StartIcon` / `EndIcon` and MudChip's `Icon` spacing as
  `start-icon` / `end-icon` on the icon in the content.
