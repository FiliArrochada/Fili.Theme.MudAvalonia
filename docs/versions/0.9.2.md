# 0.9.2

[All versions](README.md)

Nothing changes on screen: this release fixes the interface 1.0 will promise.
[Compatibility](../compatibility.md) says what a version may and may not change, and the resource
keys an app may name are listed in [Published resource keys](../published-keys.md) and pinned by a
test, beside the classes. The README's links work on nuget.org, each pointing at the release's own
commit, and the package has an icon and a description that says what it is.
