## What changed

- **[Compatibility](../compatibility.md)** says what a version may and may not change.
- **[Published resource keys](../published-keys.md)** lists the keys an app may name, pinned by a
  test beside the classes.
- **The README's links work on nuget.org**, each pointing at the release's own commit.
- **The package has an icon** and a description that says what it is.
