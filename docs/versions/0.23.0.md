# 0.23.0

[All versions](README.md)

Three of MudBlazor's options that were missing, as classes. `bordered` on a `TableView` is
MudTable's `Bordered`: table-lines between a row's cells. `always-show-scroll-buttons` on a
`TabControl` or `TabStrip` is MudTabs' `AlwaysShowScrollButtons`: the scroll buttons stay while the
tabs fit, both disabled. `default` on a toggle is MudToggleGroup's `Color.Default`, MudButton's
grey, since a toggle with no class is primary. And the tab bar's scroll arrows are
`ScrollIconColor`'s default, `Color.Inherit`: the bar's text, text-primary or a coloured bar's
contrast text, where they were action-default grey on every bar. The published class list grows to
174. See [Upgrading from 0.22.0 to 0.23.0](#upgrading-from-0220-to-0230).

## Upgrading from 0.22.0 to 0.23.0

No class or key is renamed or removed. `bordered`, `always-show-scroll-buttons` and `default` are
new words in the published class list: grep your app for them before upgrading, as an app's own
style of that name now meets the theme's. One thing looks different, as MudBlazor's does:

- **A tab bar's scroll arrows** are the bar's text colour, text-primary or a coloured bar's
  contrast text, where they were action-default grey. A disabled one is still action-disabled.
