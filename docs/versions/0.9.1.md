# 0.9.1

[All versions](README.md)

Trimmed and AOT apps that reference `Avalonia.Controls.DataGrid` start again: the theme's optional
DataGrid styles are kept through trimming. From 0.7.0 to 0.9.0 such an app threw "No precompiled
XAML found" for `DataGridStyles.axaml` at startup, and so did the browser gallery. Untrimmed apps
were never affected. Nothing to change in markup.
