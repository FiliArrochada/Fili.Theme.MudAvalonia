# 0.9.1

[All versions](README.md)

Trimmed and AOT apps that reference `Avalonia.Controls.DataGrid` start again. Nothing to change in
markup.

## What changed

- **The optional DataGrid styles survive trimming.** From 0.7.0 to 0.9.0, a trimmed or AOT app with
  the DataGrid package threw "No precompiled XAML found" for `DataGridStyles.axaml` at startup, and
  so did the browser gallery. Untrimmed apps were never affected.
