# 0.21.0

[All versions](README.md)

Two gaps the apps found moving onto 0.20.0. `placeholder` on a text field makes `PlaceholderText`
MudTextField's `Placeholder` rather than its `Label`: the hint in the empty field where the text
goes, in the text's colour at .42, with no label and no room for one. And `FiliReducedMotion`, which
MudBlazor does not have: `True` in the application's resources stops everything the theme moves or
fades on its own, in every window and popup - the ripple, popup fades, skeletons, snackbar slides,
expansion panels, overlays and the tab indicator - while a progress indicator keeps moving. The
published class list grows to 172. See [Upgrading from 0.20.0 to
0.21.0](#upgrading-from-0200-to-0210).

## Upgrading from 0.20.0 to 0.21.0

Nothing changes unless you use the new pieces.

- **One new class name**, `placeholder`: grep your app for it, as for any published class.
- **A text field that should show a hint and no label** takes `Classes="placeholder"`; its
  `PlaceholderText` is then the hint.
- **If your app has a reduced-motion setting**, set `FiliReducedMotion` from it in the
  application's resources: the theme's own animations then stop with the app's.
