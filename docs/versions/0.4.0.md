# 0.4.0

[All versions](README.md)

More of MudSlider, unchecked colours and the grey tokens. A slider with no class looks different;
see [Upgrading](#upgrading-from-03-to-04).

## What changed

- **Slider:** MudSlider's `Variant`, `TickMarks` and `ValueLabel` as `filled`, tick dots through
  `TickPlacement`, and `value-label`.
- **Checkboxes and radios:** `UncheckedColor` as `unchecked-{colour}`.
- **Tokens:** `GrayDefault` … `GrayDarker`.
- **Fix:** an outlined text field's or select's floated label is no longer cut off along its top
  edge.

## Upgrading from 0.3 to 0.4

- **A slider with no variant class is MudSlider's `Variant.Text`**: the whole rail is the colour
  at 30%, with no solid part. 0.3 drew the part up to the thumb solid on every slider; add
  `filled` for that.
