# 0.4.0

[All versions](README.md)

MudSlider's `Variant`, `TickMarks` and `ValueLabel`: `filled`, tick dots through `TickPlacement`,
and `value-label`. `UncheckedColor` on checkboxes and radios as `unchecked-{colour}`. The
`GrayDefault` … `GrayDarker` tokens. An outlined text field's or select's floated label is no longer
cut off along its top edge. See [Upgrading from 0.3 to 0.4](#upgrading-from-03-to-04).

## Upgrading from 0.3 to 0.4

- **A slider with no variant class is MudSlider's `Variant.Text`**: the whole rail is the colour
  at 30%, with no solid part. 0.3 drew the part up to the thumb solid on every slider; add
  `filled` for that.
