# 0.32.0

[All versions](README.md)

A window's or a `ThemeVariantScope`'s own variant now restyles everything inside it, and the
glyphs in a Panel in an icon button take the button's icon size again.

## What changed

- **A window or a `ThemeVariantScope` paints in its own variant.** Every brush is declared in each
  variant's dictionary, so a dark panel in a light app, or a high contrast window, is that variant
  through and through; before, its brushes stayed in the application's variant while its colour
  keys followed, and half of it changed. A colour an app sets in its application's resources still
  reaches every variant's brushes, and `FindResource(key)` in code, naming no variant, still finds
  the brush for the application's variant. The keyboard focus ring takes the variant of the control it
  frames, and its two brushes can now be set in a container's resources too
  ([Compatibility](../compatibility.md)). The brushes the forked TabbedPage and NavigationPage
  declare themselves follow the variant as well.
- **The glyphs in a Panel in an icon button take the button's icon size.** Two glyphs swapped in a
  Panel, the toggled-icon idiom included, were left at 24px on a `small` or `large` icon button;
  they now take its 20, 36 or 32px, as a glyph directly in the button does. A glyph in a flyout the
  button opens keeps its own size.
- **How a control opts out of the focus ring is documented.** A `FocusAdorner` set to `{x:Null}`,
  in a style or on the control, leaves that control without the ring; one left unset takes it, a
  control the app templates itself included ([Published keys](../published-keys.md)).

## Upgrading from 0.31.0 to 0.32.0

Nothing has to change. Three things may now be removed or rechecked:

- **A `ThemeVariantScope` that changed only half of what it held** now changes all of it. An app
  that kept one, or set a variant on a window, should look at that part of its UI again; one that
  removed a scope because it did not work can put it back.
- **A `Width`/`Height` or a size class set on a glyph in a Panel in an icon button**, to size it as
  the button's icon, can go: the theme sizes it now. One set to a different size still wins.
- **A brush looked up in code.** With a variant, `TryFindResource(key, variant, out value)` now
  gets that variant's brush rather than the application's. With none, `FindResource(key)` gets a
  brush of the same colour as before, but not the object a control paints with: compare colours,
  not instances, or pass the control's `ActualThemeVariant`.
