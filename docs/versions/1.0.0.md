# 1.0.0

[All versions](README.md)

1.0, the first stable release: the theme is 1.0.0-rc.2's, unchanged, on Avalonia 12.1.5 and
MudBlazor 9.12. From here a minor or patch version keeps every class, resource key and include
path an app names, as [Compatibility](../compatibility.md) lists, and fixes go into the newest 1.x.

## What changed

- **The theme is 1.0.0-rc.2's.** No style, key, class or template changed: an app on the release
  candidate moves to 1.0.0 without a change.
- **MudDataGrid's toolbar has a parity row.** `ToolBarContent` and `ToolBarWrapContent` are a
  `Border` with the `toolbar` class above the `DataGrid`, with a `WrapPanel` inside where its
  content should wrap.
- **A shorter package page.** The README, which is the nuget.org page, drops its repeats and
  sends contributors to [Contributing](../../CONTRIBUTING.md).

## Upgrading from 1.0.0-rc.2 to 1.0.0
Nothing to change: raise the package version. An app on an earlier version follows
[Upgrading from 0.33.0 to 1.0.0-rc.1](1.0.0-rc.1.md#upgrading-from-0330-to-100-rc1) and
[Upgrading from 1.0.0-rc.1 to 1.0.0-rc.2](1.0.0-rc.2.md#upgrading-from-100-rc1-to-100-rc2) first.
