# 0.33.0

[All versions](README.md)

No change to the theme: the styles, resources and keys are 0.32.0's. The README, which is also
this package's page on nuget.org, now installs the newest release without naming a version.

## What changed

- **The install steps name no version.** The README's Install section uses
  `dotnet add package`, which adds the newest release and, under Central Package Management, writes
  its version into `Directory.Packages.props`; the NuGet badge shows which version that is. The
  bug report form asks for the version an app uses rather than suggesting one.

## Upgrading from 0.32.0 to 0.33.0

Nothing has to change.
